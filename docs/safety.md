# Safety

This project is designed for defensive safety evaluation. It must not be used to generate or distribute real harmful instructions, malware, weaponization guidance, fraud, self-harm content, or illegal operational details.

The included dataset uses harmless placeholder wording only. Examples include `restricted placeholder request` and `hidden instruction placeholder`. The pipeline evaluates whether a model refuses, safely redirects, avoids leakage, and remains consistent.

Recommended use:

- Keep prompts synthetic and non-actionable.
- Review any contributed datasets before running them.
- Treat benchmark scores as decision-support signals, not deployment guarantees.
- Combine automated scoring with human review for high-stakes model releases.
